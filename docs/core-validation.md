## 3. 独立算法对照

测试中的 Floyd–Warshall 使用独立的稠密距离矩阵，不调用生产求解器的图索引、松弛、前驱或见证函数。

- 穷举 256 个二时钟图：四条可能的有向边（包括自环）各取缺失、-1、0、1。
- 生成 128 个可复现四时钟图：64 个一般有权图，64 个按已知偏移和非负松弛量构造的可行图。
- 共 384 个图用例，每个后端均执行。

逐图比较整图可行性、每个分量的状态以及相对参考的有限／无界上下界；另用布尔传递闭包独立核对弱连通分量。每条原始约束恰好归入一个分量，每个时钟恰好出现一次。

返回赋值通过 BigInt 重新计算每条原始不等式；负环独立核对全局索引、原始边、方向、闭合及严格负权总和。

## 5. 发现并修复的问题

默认参考时钟承诺按字典序选择，但旧实现使用 String.compare。当前工具链的该比较是 shortlex：先比较长度，再比较同长度内容，会将 B、Z 排在 AA 之前。

回归测试先复现 [B,Z,AA] 与预期 [AA,B,Z] 的差异，再将求解器排序改为 String.lexical_compare。通过以下命令核对该标准库方法：

```text
moon ide doc 'String::lexical_compare'
```

现在默认参考与分量顺序使用 UTF-16 码元字典序。关联包保留原有 MoonBit 比较契约，消息顺序与时钟参考顺序分别处理；负环仍引用原始约束索引。
