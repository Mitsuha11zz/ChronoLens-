# 样例目录

four-events.jsonl 是方案中的四事件合成输入样例。当前预期：输入有效、4 条事件、2 个时钟域、没有输入诊断；形成 a1→b1、b2→a2 两个唯一配对。集成黑盒测试包含该四事件数据。

以 A 为参考、容差为 0 时，B 的偏移范围为 [100,160] ms。2026-10-18 的核心流水线测试已确认该结果；切换到 B 为参考时，A 的区间为 [-160,-100] ms。

后续按功能继续补充实际日志转换样例。

mixed-associations.jsonl 包含 6 条事件、3 个消息组：a 为唯一配对，b 缺少接收，c 存在两个发送候选。预期统计为 1 个配对组、2 个未解决组、1 个缺失组、1 个歧义组；配对测试覆盖同结构的混合场景。

negative-cycle.jsonl 是三时钟、六事件的合成冲突样例。零容差时，三组消息分别形成 o_A-o_B ≤ -10、o_B-o_C ≤ -10、o_C-o_A ≤ -10（单位微秒）；相加得到 0 ≤ -30。核心流水线测试已确认三条边形成闭环且权重和为 -30 微秒，并核对其原始消息来源。

component-analysis.jsonl 包含 9 条事件、6 个时钟域，数学预期形成四个弱连通分量：

| 分量 | 参考时钟 | 零容差时的数学预期 |
| --- | --- | --- |
| A、B | A | A 为 [0,0]；B 为 [100000,160000] 微秒 |
| C、D | C | C 为 [0,0]；D 下界 -50 微秒，上界无界 |
| E | E | 只有缺失接收的事件，没有约束边；自身相对偏移为 [0,0] |
| F | F | 自环权重 -10 微秒，冲突 |

默认参考或显式指定 A 均可得到以上参考选择。E 的 [0,0] 仅来自自身坐标定义，不能与其他分量比较时间。核心流水线测试已确认四个分量独立报告，F 冲突没有阻止 A/B 和 C/D 的区间分析。

为在四后端运行，测试使用上述文件的内嵌副本；scripts/check-fixture-copies.ps1 已核对四份副本与当前 JSONL 内容一致（忽略行尾形式和末尾换行）。这是核心 API 验证，不包含 CLI 文件读取或真实服务采集，详见 docs/core-validation.md。
