# 样例目录

four-events.jsonl 是方案中的四事件合成输入样例。当前预期：输入有效、4 条事件、2 个时钟域、没有输入诊断；形成 a1→b1、b2→a2 两个唯一配对。集成黑盒测试包含该四事件数据。

未来求解阶段的预期：以 A 为参考、容差为 0 时，B 的偏移范围为 [100,160] ms。此求解结论尚未由本项目实现或验证。

后续按功能继续加入单向无界、关联歧义、独立分量和负环冲突样例。

mixed-associations.jsonl 包含 6 条事件、3 个消息组：a 为唯一配对，b 缺少接收，c 存在两个发送候选。预期统计为 1 个配对组、2 个未解决组、1 个缺失组、1 个歧义组；配对测试覆盖同结构的混合场景。
