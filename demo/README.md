# ChronoLens 本地交互演示

交互演示提供一个本地浏览器工作台，用于载入 JSONL 事件、调用 MoonBit CLI 分析，并查看偏移区间、代表时间线和冲突证据。界面不重复实现分析算法，所有诊断都来自正式 `cmd/chronolens` native CLI。

## 启动

在项目根目录运行：

```text
python demo/server.py
```

启动时需要 `python` 与 `moon` 均已加入 `PATH`。服务会先构建 native CLI，然后监听 `http://127.0.0.1:8765`。在浏览器打开该地址即可；按 `Ctrl+C` 停止服务。实现只使用 Python 标准库，不需要 npm 安装或额外依赖。

服务仅绑定本机回环地址。事件文本写入临时目录交给本机 CLI 分析，请求完成后自动清理；项目不会把日志发送到外部服务。单次请求的 JSONL 上限为 8 MiB，CLI 分析超时为 120 秒。

## 工作台功能

- 使用四份内置样例，或导入、拖放、直接编辑 UTF-8 JSONL。
- 设置消息关系容差和可选参考时钟。
- 查看输入事件、唯一消息配对、约束分量和约束数量摘要。
- 对每个分量查看时钟偏移边际范围、代表解及分量状态。
- 查看一组由求解器代表解绘制的时间线；点选事件可回看原始字段。
- 查看负环约束及其消息／事件证据，点选证据可跳转到事件。
- 导出完整的 `chronolens.diagnostic.v1` JSON 报告。

超过 160 条的分量时间线会均匀抽样绘制，事件列表最多直接展示 240 条；JSON 导出保留完整报告。

## 解释边界

偏移范围依赖固定时钟偏移模型、消息关联和观测记录。每个分量拥有独立参考坐标，代表时间线不是 UTC，也不能比较不同分量。区间上下端点分别求得，未必能同时取到。负环证明当前约束集合不可同时满足，但不单独指出根因。

该演示服务面向本机试用，不是部署用的 Web 服务；多机器时钟表现、真实业务接入与生产容量仍需单独验证。
